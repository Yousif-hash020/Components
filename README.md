# Auth Components Library

A personal collection of reusable, pre-built components for authentication flows. Instead of rebuilding login, register, and dashboard boilerplate for every new project, this repo serves as a drop-in starting point.

## What's Inside

- Login component
- Register component
- Dashboard boilerplate with route protection
- Token handling and session management patterns

## Why This Exists

Every project needs the same auth foundation. This repo saves time by keeping tested, working components in one place — just copy, connect to your backend, and customize as needed.

## Usage

1. Copy the relevant component into your project
2. Update endpoint URLs to match your backend
3. Adjust field names/payloads as needed
4. Style to fit your project
